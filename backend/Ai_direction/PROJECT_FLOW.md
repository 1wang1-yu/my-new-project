## 智能问答流程（RAG核心）

```
用户提问："断桥有什么历史故事？"
          │
          ▼
┌─────────────────────────────────────┐
│     ChatController.chat()           │
│     接收用户问题                     │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│     KnowledgeService                │
│     retrieveContext()               │
│     从ChromaDB检索相关知识           │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│     构建提示词：                    │
│     "用户问题：断桥有什么历史故事？  │
│      知识库：[相关文档1,文档2...]"   │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│     LlmClient.chat()                │
│     调用阿里通义大模型               │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│     提取回答和建议追问              │
│     返回AI回答给用户                │
└─────────────────────────────────────┘
```

## ChromaDB（向量数据库）说明

```
MySQL数据：精确匹配
SELECT * FROM food WHERE name = '红烧肉'

ChromaDB数据：语义搜索
用户问："有什么好吃的？"
         ↓
语义相似度匹配 → 返回"红烧肉"、"糖醋排骨"等美食文档

这就是为什么需要ChromaDB：
- 让AI知道景区有什么景点、故事、历史
- 而不是让AI只能精确匹配某个词
```

## 下一步行动

1. **启动ChromaDB**（必须）
   ```bash
   docker run -d -p 8000:8000 chromadb/chroma
   ```

2. **测试智能问答**
   - 启动后端
   - 调用 `/api/v1/chat` 接口
   - 看是否能返回AI回答

3. **调试大模型调用**
   - 如果返回固定文案，说明API调用失败
   - 检查API密钥和配置

## 快速理解总结

**一句话总结这个项目**：
> "这是一个用AI大模型回答景区问题的系统，知识库检索让AI知道景区的专业知识，ChromaDB存储这些知识，大模型负责理解和回答。"

**与苍穹外卖的核心区别**：
- 苍穹外卖：查数据库 → 返回数据
- 这个项目：检索知识库 → 调用AI → 返回回答

**最需要理解的3个类**：
1. `LlmClient` - 调用大模型
2. `KnowledgeService` - 检索知识库
3. `ChatService` - 整合两者，协调整个流程
